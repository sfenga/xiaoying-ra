# frontend

素材工坊前端（Next.js 14 App Router + React + TypeScript + Tailwind CSS）。

启动、测试与配置说明见仓库根目录 [README.md](../README.md)。

常用命令：

```bash
npm ci            # 安装依赖
npm run dev       # 开发模式 http://localhost:3000
npm test          # vitest 单元测试
npm run lint      # eslint
npx tsc --noEmit  # 类型检查
npm run build     # 生产构建
```
